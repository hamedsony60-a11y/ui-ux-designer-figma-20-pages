# استخدام طراح UI/UX مسلط به Figma

## طراحی رابط کاربری وب‌سایت (۲۰ صفحه)

ما به یک **طراح UI/UX حرفه‌ای و مسلط به Figma** نیاز داریم برای طراحی کامل رابط کاربری یک وب‌سایت در ۲۰ صفحه.

هدف اصلی: ارائه طرحی **مدرن، تمیز، کاربرپسند و کاملاً قابل پیاده‌سازی** توسط تیم فرانت‌اند.

---

## دامنه کار (Scope)

- طراحی **۲۰ صفحه** (وایرفریم دقیق + UI نهایی) مطابق نیازهای محصول
- طراحی سیستم کامپوننت‌ها و استایل‌ها در Figma  
  (Buttons, Inputs, Cards, Tables, Modal, Alerts و سایر کامپوننت‌های مورد نیاز)
- طراحی حالت‌های تعاملی: **Hover / Active / Disabled** برای کامپوننت‌های اصلی
- طراحی نسخه **Desktop** (الزامی)
- در صورت توافق: طراحی **Responsive** برای Tablet و Mobile (قیمت جداگانه یا داخل پیشنهاد)

---

## تحویل‌ها (Deliverables)

- فایل اصلی Figma (لینک + دسترسی ادیت)
- **Style Guide** کامل شامل:
  - پالت رنگ‌ها
  - تایپوگرافی
  - فاصله‌ها (Spacing System)
  - آیکن‌استایل و قوانین استفاده
- **پروتوتایپ قابل کلیک** برای مسیرهای اصلی (حداقل ۲–۳ فلو اصلی)
- خروجی آماده برای پیاده‌سازی:
  - Auto-layout
  - Components + Variants
  - Naming استاندارد و ساختار منظم فایل

---

## ورودی‌هایی که ارائه می‌دهیم

- ساختار صفحات / سایت‌مپ و لیست کامل ۲۰ صفحه
- محتوای متنی اولیه یا نمونه (در صورت نبود محتوا، Lorem استفاده می‌شود)
- لوگو و هویت بصری (در صورت موجود بودن) یا نمونه‌های رفرنس
- نمونه سایت‌های رقیب / الهام (در صورت نیاز)

---

## زمان‌بندی پیشنهادی

| فاز | شرح | مدت زمان |
|-----|-----|----------|
| فاز ۱ | وایرفریم و ساختار کلی | ۷ روز |
| فاز ۲ | UI نهایی صفحات | ۳۰ روز |
| فاز ۳ | ریوایز و تحویل نهایی | ۱۰ روز |

**مجموع تقریبی: ۴۷ روز**

---

## اصلاحات (Revisions)

- ۲ مرحله اصلاح برای هر صفحه **یا**
- ۲ راند کلی روی کل پروژه  
(طبق توافق نهایی در پیشنهاد)

---

## شرایط مهم

- خروجی باید کاملاً **قابل توسعه و استاندارد Figma** باشد  
  (Components / Variants / Auto-layout / Naming تمیز)
- کپی یا استفاده از UI آماده بدون اجازه یا بدون ذکر منبع **قابل قبول نیست**
- تسویه حساب **مرحله‌ای بر اساس Milestone** (ترجیحی)

---

## نحوه ارسال پیشنهاد

لطفاً پیشنهاد خود را شامل موارد زیر ارسال کنید:

1. نمونه کارهای قبلی مرتبط (لینک Figma یا Behance/Dribbble)
2. قیمت پیشنهادی (Desktop only / با Responsive)
3. زمان‌بندی دقیق‌تر در صورت نیاز
4. تعداد راند اصلاحات پیشنهادی
5. روش ارتباط و نحوه همکاری

---

**آماده شروع همکاری هستیم.**  
اگر تجربه طراحی سیستم‌های UI تمیز و قابل توسعه دارید، خوشحال می‌شویم با شما کار کنیم.
